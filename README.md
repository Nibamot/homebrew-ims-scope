# homebrew-ims-scope

Homebrew tap for [IMS-Scope](https://github.com/Nibamot/ims-scope), a fork of
[Freelens](https://github.com/freelensapp/freelens).

## Install

```sh
brew tap Nibamot/ims-scope
brew install --cask ims-scope
```

Builds are not Apple-notarized; the cask clears the quarantine attribute
after install so Gatekeeper does not block the app.
